## 🚀 每日必用命令

### 基础检查
```bash
# 环境验证
python scripts/check_installation.py

# 代码格式化
black discoverse/ tests/
isort discoverse/ tests/

# 代码检查
flake8 discoverse/ --max-line-length=100
```

### 运行测试
```bash
# 所有单元测试（快速）
pytest tests/unit/ -v

# 特定模块
pytest tests/unit/test_simulator.py -v

# 带覆盖率
pytest tests/ --cov=discoverse --cov-report=html
# 查看: open htmlcov/index.html

# 并行执行（4倍速）
pytest tests/ -n auto

# 只运行失败的测试
pytest --lf

# 性能基准测试
pytest tests/benchmarks/ --benchmark-only
```

### 标记（Markers）
```bash
# 只跑单元测试
pytest -m unit -v

# 跳过慢速测试
pytest -m "not slow" -v

# 仿真测试（需要GPU）
pytest -m simulation -v

# MMK2 专项
pytest -m mmk2 -v

# 组合标记
pytest -m "simulation and not slow" -v
```

### CICD 测试框架
```bash
# 单个机器人单个任务
python examples/universal_tasks/cicd_testing.py \
  --robots airbot_play \
  --tasks place_block

# 批量测试（无头模式）
python examples/universal_tasks/cicd_testing.py \
  --robots airbot_play panda ur5e \
  --tasks place_block cover_cup \
  --headless \
  --timeout 300 \
  --report test_report.json

# 解析报告
python scripts/parse_cicd_report.py test_report.json
```

### Docker
```bash
# 构建测试镜像
docker build -f discoverse/docker/Dockerfile.test -t discoverse:test .

# 运行单元测试
docker run --rm discoverse:test pytest tests/unit/ -v

# 运行仿真测试（需要GPU）
docker run --gpus all --rm discoverse:test pytest tests/simulation/ -v

# Docker Compose 编排
docker-compose -f docker-compose.test.yml up
docker-compose -f docker-compose.test.yml down
```

## 🎯 测试编写模板

### 单元测试模板
```python
# tests/unit/test_example.py
import pytest
import numpy as np

class TestExampleModule:
    """示例模块测试"""
    
    @pytest.fixture
    def sample_data(self):
        """测试数据 fixture"""
        return np.random.rand(10, 3)
    
    def test_basic_functionality(self, sample_data):
        """测试基本功能"""
        result = some_function(sample_data)
        assert result is not None
        assert len(result) == 10
    
    @pytest.mark.parametrize("input_val,expected", [
        (0, 0),
        (1, 1),
        (2, 4),
    ])
    def test_with_parameters(self, input_val, expected):
        """参数化测试"""
        assert square(input_val) == expected
```

### 集成测试模板
```python
# tests/integration/test_robot_task.py
import pytest
from discoverse.envs import make_env

class TestRobotTask:
    """机器人任务集成测试"""
    
    @pytest.fixture
    def env(self):
        """创建测试环境"""
        env = make_env('airbot_play', 'place_block', seed=42)
        yield env
        env.close()
    
    def test_task_execution(self, env):
        """测试任务执行"""
        obs = env.reset()
        
        for _ in range(100):
            action = env.action_space.sample()
            obs, reward, done, info = env.step(action)
            
            if done:
                assert info.get('success', False)
                break
```

### MMK2 专项测试模板
```python
# tests/mobile_manipulation/test_mmk2_example.py
import pytest
from discoverse.envs import make_env
from discoverse.robots.mmk2.mmk2_fik import MMK2FIK

@pytest.mark.mmk2
class TestMMK2Control:
    """MMK2 控制测试"""
    
    def test_differential_drive(self):
        """测试差速驱动"""
        env = make_env('mmk2', 'navigation', seed=42)
        env.reset()
        
        # 直线运动
        for _ in range(100):
            action = np.zeros(19)
            action[0] = 0.5  # 左轮
            action[1] = 0.5  # 右轮
            env.step(action)
        
        # 验证位置变化
        pos = env.get_base_position()
        assert pos[0] > 0.3  # 前进 > 30cm
```

## 🐛 常见问题排查

### 问题 1: 测试找不到模块
```bash
# 确保已安装项目
pip install -e .

# 或者设置 PYTHONPATH
export PYTHONPATH=$PYTHONPATH:/path/to/DISCOVERSE
```

### 问题 2: MuJoCo 渲染错误
```bash
# 设置渲染后端
export MUJOCO_GL=glfw    # 有显示器
export MUJOCO_GL=osmesa  # 无显示器（CI环境）
export MUJOCO_GL=egl     # GPU加速无头渲染

# 测试 MuJoCo 安装
python scripts/check_mujoco_install.py
```

### 问题 3: GPU 不可用
```bash
# 检查 CUDA
nvidia-smi

# 检查 PyTorch CUDA
python -c "import torch; print(torch.cuda.is_available())"

# Docker GPU 支持
docker run --gpus all nvidia/cuda:11.8.0-base nvidia-smi
```

### 问题 4: 测试超时
```bash
# 增加超时时间
pytest tests/ --timeout=600

# 或在 pyproject.toml 中配置
# [tool.pytest.ini_options]
# timeout = 600
```

### 问题 5: 覆盖率数据不准确
```bash
# 清除旧的覆盖率数据
rm -rf .coverage htmlcov/

# 重新运行
pytest tests/ --cov=discoverse --cov-report=html
```

## 🔧 pytest 标记（Markers）速查

| 标记 | 用途 | 示例 |
|------|------|------|
| `unit` | 单元测试（快速） | `@pytest.mark.unit` |
| `integration` | 集成测试（中速） | `@pytest.mark.integration` |
| `simulation` | 仿真测试（需要MuJoCo） | `@pytest.mark.simulation` |
| `kinematics` | 运动学测试 | `@pytest.mark.kinematics` |
| `sensors` | 传感器测试 | `@pytest.mark.sensors` |
| `policies` | 策略测试 | `@pytest.mark.policies` |
| `mobile` | 移动操作测试 | `@pytest.mark.mobile` |
| `mmk2` | MMK2 专项 | `@pytest.mark.mmk2` |
| `e2e` | 端到端测试（慢速） | `@pytest.mark.e2e` |
| `slow` | 长时间测试（>30s） | `@pytest.mark.slow` |
| `gpu` | 需要 GPU | `@pytest.mark.gpu` |
| `benchmark` | 性能基准测试 | `@pytest.mark.benchmark` |

**使用示例**：
```python
@pytest.mark.simulation
@pytest.mark.mmk2
def test_mmk2_simulation():
    """MMK2 仿真测试"""
    pass
```

## ⚡ 效率提示

### 1. 使用别名（添加到 ~/.bashrc）
```bash
alias pt='pytest tests/ -v'
alias ptc='pytest tests/ --cov=discoverse --cov-report=html'
alias ptf='pytest --lf -v'
alias cicd='python examples/universal_tasks/cicd_testing.py'
```

### 2. 预提交钩子
```bash
# 安装 pre-commit
pip install pre-commit

# 启用钩子
pre-commit install

# 现在每次 git commit 会自动运行 black, isort, flake8
```

### 3. VS Code 配置
```json
// .vscode/settings.json
{
    "python.testing.pytestEnabled": true,
    "python.testing.pytestArgs": ["tests/"],
    "python.linting.flake8Enabled": true,
    "python.formatting.provider": "black"
}
```

### 4. 快速查看覆盖率
```bash
# 安装 coverage
pip install coverage

# 运行并生成报告（一行命令）
pytest tests/ --cov=discoverse --cov-report=term-missing | grep -A 100 "TOTAL"
```
