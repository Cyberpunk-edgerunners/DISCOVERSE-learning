### 2.2 IK 求解内部流程

```
converge_ik(dt)
    │
    ├─→ Iteration 1
    │     │
    │     ├─→ mink.solve_ik()
    │     │     │
    │     │     ├─→ 1. 计算当前末端位姿
    │     │     │     FK(q_current) → T_current
    │     │     │
    │     │     ├─→ 2. 计算位姿误差
    │     │     │     error = log(T_current^-1 * T_target)
    │     │     │     v_target = error / dt
    │     │     │
    │     │     ├─→ 3. 计算雅可比矩阵
    │     │     │     J = ∂(end_pose) / ∂q
    │     │     │
    │     │     ├─→ 4. 构造 QP 问题
    │     │     │     minimize: ||J*dq - v||² + λ*||dq-dq0||²
    │     │     │     subject to: q_min ≤ q+dq*dt ≤ q_max
    │     │     │
    │     │     └─→ 5. 调用 quadprog 求解
    │     │           dq* = argmin(QP)
    │     │
    │     ├─→ configuration.integrate(dq*, dt)
    │     │     q_new = q_old + dq* * dt
    │     │
    │     └─→ check error
    │           err = compute_error(q_new)
    │           if ||err|| < threshold: break
    │
    ├─→ Iteration 2
    │     │ (重复上述步骤)
    │     └─→ ...
    │
    └─→ Iteration N
          └─→ converged = True/False
```

### 3.3 位置控制 vs 阻抗控制时序对比

**位置控制模式**:
```
pre_step()  → _proc_mink_ik() → mj_data.ctrl = q_target
                                        ↓
                                   mj_step()
                                        ↓
                            MuJoCo 内部 PD 控制器
                                        ↓
                               tau = kp*(q_target-q)
                                        ↓
                                  正向动力学
                                        ↓
                                qpos, qvel 更新
```

**阻抗控制模式**:
```
pre_step()  → _proc_mink_ik() → ID_controller.set_target(q_target)
                                        ↓
                                   mj_step() loop:
                                        ↓
                            ID_controller.update_state(q, dq, tau)
                                        ↓
                            tau = kp*(q_target-q) + kd*dq + gravity
                                        ↓
                            mj_data.ctrl = tau
                                        ↓
                                   mj_step()
                                        ↓
                                  正向动力学
                                        ↓
                                qpos, qvel 更新
```
