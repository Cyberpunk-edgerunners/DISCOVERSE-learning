```python
# 文件: mocap_ik_manipulator.py:436-462
def _proc_mink_ik(self):
    # === 步骤 1: 获取目标位姿 ===
    # 从 MuJoCo mocap body 读取目标 SE3 变换
    mink_target_se3 = mink.SE3.from_mocap_name(
        self.mj_model, 
        self.mj_data, 
        self.mocap_name  # "target"
    )
    
    # === 步骤 2: 设置 IK 任务目标 ===
    self.end_effector_task.set_target(mink_target_se3)
    
    # === 步骤 3: 迭代求解 IK ===
    res = self.converge_ik(self.mj_model.opt.timestep)
    
    # === 步骤 4: 应用求解结果 ===
    if self.impedance_control:
        # 阻抗控制模式: 设置期望关节角度
        q_desired = self.configuration.q[:self.arm_dof]
        self.ID_controller.set_target(q_desired)
    else:
        # 位置控制模式: 直接设置关节控制命令
        self.mj_data.ctrl[:self.arm_dof] = self.configuration.q[:self.arm_dof]
    
    # === 步骤 5: 可视化反馈 ===
    if res:
        # IK 成功 -> 绿色
        self.mj_model.geom(self.mocap_box_name).rgba = (0.3, 0.6, 0.3, 0.2)
    else:
        # IK 失败 -> 红色
        self.mj_model.geom(self.mocap_box_name).rgba = (0.6, 0.3, 0.3, 0.2)
```

## 4. IK 收敛算法详解

### 4.1 迭代求解 (converge_ik)

```python
# 文件: mocap_ik_manipulator.py:201-211
def converge_ik(self, dt):
    for iteration in range(self.MINK_MAX_ITERS):  # 最多 10 次迭代
        # === 步骤 1: 求解关节速度 ===
        vel = mink.solve_ik(
            self.configuration,    # 当前关节配置
            self.mink_tasks,       # 任务列表 [FrameTask, PostureTask]
            dt,                     # 时间步长 0.002s
            self.MINK_SOLVER,      # "quadprog"
            1e-3                    # damping
        )
        
        # === 步骤 2: 积分更新关节位置 ===
        self.configuration.integrate_inplace(vel, dt)
        
        # === 步骤 3: 计算误差 ===
        err = self.end_effector_task.compute_error(self.configuration)
        
        # === 步骤 4: 检查收敛 ===
        pos_achieved = np.linalg.norm(err[:3]) <= 1e-3  # 1mm
        ori_achieved = np.linalg.norm(err[3:]) <= 1e-3  # ~0.057°
        
        if pos_achieved and ori_achieved:
            return True  # 收敛成功
    
    return False  # 未收敛
```

**关键参数**:
- `MINK_MAX_ITERS = 10`: 最大迭代次数
- `MINK_POS_THRESHOLD = 1e-3`: 位置误差阈值 (1mm)
- `MINK_ORI_THRESHOLD = 1e-3`: 姿态误差阈值
- `MINK_SOLVER = "quadprog"`: QP 求解器

### 4.2 Mink 任务配置

```python
# 文件: mocap_ik_manipulator.py:317-329
def _prepare_mink(self):
    # === 1. 创建配置对象 ===
    self.configuration = mink.Configuration(self.mj_model)
    
    # === 2. 末端执行器任务 ===
    self.end_effector_task = mink.FrameTask(
        frame_name="endpoint",      # 目标 site 名称
        frame_type="site",          # 类型: site
        position_cost=100.0,        # 位置权重 (高优先级)
        orientation_cost=10.0,      # 姿态权重
        lm_damping=1.0,            # Levenberg-Marquardt 阻尼
    )
    
    # === 3. 姿态任务 (正则化) ===
    self.posture_task = mink.PostureTask(
        model=self.mj_model, 
        cost=1e-2               # 低权重 (保持初始姿态)
    )
    
    # === 4. 任务列表 ===
    self.mink_tasks = [self.end_effector_task, self.posture_task]
```

## 5. 底层数学原理

### 5.1 IK 问题建模

**目标**: 给定末端位姿 $T_{target} \in SE(3)$，求关节速度 $\dot{q}$

**QP 优化问题**:
```
minimize: ||J * dq - v_target||² + λ * ||dq - dq_posture||²
subject to: q_min ≤ q + dq*dt ≤ q_max
            dq_min ≤ dq ≤ dq_max
```

其中:
- `J`: 雅可比矩阵 (6×n)
- `dq`: 关节速度 (n×1)
- `v_target`: 末端期望速度 (6×1)
- `λ`: 姿态任务权重 (1e-2)

### 5.2 Mink 内部流程

```
mink.solve_ik()
  ├─> 1. 计算雅可比矩阵 J = ∂(end_effector_pose) / ∂q
  ├─> 2. 构造 QP 问题
  │     minimize: position_cost * ||J_pos * dq - v_pos||²
  │              + orientation_cost * ||J_ori * dq - v_ori||²
  │              + posture_cost * ||dq - dq_0||²
  ├─> 3. 调用 qpsolvers.solve_problem(solver="quadprog")
  └─> 4. 返回最优关节速度 dq*
```

**使用的求解器**:
- 主求解器: `quadprog` (积极集法, Active Set Method)
- 备用求解器: `daqp` (对偶积极集法)

### 6.2 阻抗控制模式 (force 模式)

```python
# 文件: examples/force_control/impedance_control.py
class ImpedanceController:
    def compute_torque(self):
        # 1. 计算关节误差
        q_error = self.q_target - self.q_current
        dq_error = 0 - self.dq_current
        
        # 2. PD 控制 + 重力补偿
        torque = self.kp * q_error + self.kd * dq_error + self.gravity_comp
        
        # 3. 外力估计 (可选)
        self.external_force = self.tau_measured - torque
        
        return torque
```

**参数**:
- `kp = [100, 100, 100, 5, 100, 5]`: 比例增益
- `kd = [5, 5, 5, 0.5, 0.5, 0.1]`: 微分增益

**适用场景**:
- 力控任务
- 接触交互
- 真实机器人部署

## 8. 工程视角分析

### 8.1 系统解决的核心问题

**问题**: 如何让用户直观地控制高自由度机械臂？

**解决方案**:
1. **用户空间**: 拖动末端位姿 (6D)
2. **算法空间**: IK 求解关节角度 (6D/7D)
3. **执行空间**: MuJoCo 物理仿真驱动

**关键技术**:
- 实时 IK 求解 (< 1ms)
- QP 优化保证平滑性
- 多任务权重平衡

### 8.2 分层设计的优势

```
用户交互层 (mocap)
  ↓ 解耦
IK 求解层 (mink)
  ↓ 解耦
控制层 (position/impedance)
  ↓ 解耦
物理层 (MuJoCo)
```

**好处**:
1. **可替换性**: 可以替换 IK 求解器 (mink → pinocchio)
2. **可扩展性**: 增加新的控制模式 (MPC, RL)
3. **可测试性**: 每层独立测试
4. **实时性**: IK 层异步求解,不阻塞渲染

### 8.3 线程模型

**当前实现**: 单线程顺序执行

```
主线程:
  while True:
    pre_step()    # IK 求解 ~1ms
    mj_step() x4  # 物理仿真 ~2ms
    sync()        # 渲染 ~3ms
    sleep()       # 帧率控制
```

**性能瓶颈**:
- IK 求解: 10 次迭代 × QP求解
- 物理仿真: 4 次积分
- 渲染: 取决于场景复杂度

**优化方向**:
1. IK 异步求解 (单独线程)
2. 降低 IK 迭代次数
3. 使用更快的 QP 求解器

### 8.4 可靠性保证

**IK 失败处理**:
```python
if not res:  # IK 未收敛
    # 1. 视觉反馈: 红色方块
    # 2. 保持上一次有效结果
    # 3. 不更新控制命令
```

**数值稳定性**:
- Levenberg-Marquardt 阻尼: 防止奇异
- 关节限位检查: QP 约束
- 速度限制: dq_max

**实时性保证**:
- 最大迭代次数限制: 10 次
- 早停策略: 误差 < 阈值
- 帧率控制: 125 Hz 固定

### 8.5 实时性分析

**时间预算** (125 Hz → 8ms/frame):
- IK 求解: ~1ms (10 迭代 × 0.1ms)
- 物理仿真: ~2ms (4 步 × 0.5ms)
- 渲染: ~3ms
- 余量: ~2ms

**瓶颈识别**:
```python
# 潜在实时性问题
1. QP 求解: O(n³) 复杂度, n=关节数
2. 雅可比计算: 需要前向运动学
3. 渲染: 如果启用 3DGS, 可能 >10ms
```

        self.model = load_model("airbot_play")
        self.solver = MinkIKSolver(self.model)
    
    def test_ik_convergence(self):
        """测试 IK 收敛性"""
        target = SE3.from_xyz_quat([0.3, 0, 0.2], [1,0,0,0])
        q_init = np.zeros(6)
        
        q_result, converged = self.solver.solve(target, q_init, dt=0.01)
        
        self.assertTrue(converged)
        
        # 前向运动学验证
        pose_result = self.model.forward_kinematics(q_result)
        error = pose_result.distance(target)
        self.assertLess(error, 1e-3)
    
    def test_joint_limits(self):

### Q1: IK 求解失败怎么办?

**现象**: 红色目标框，机器人不动

**原因**:
1. 目标位姿超出工作空间
2. 奇异位形 (雅可比矩阵退化)
3. 初始关节角度不良

**解决**:
```python
# 方法 1: 检查工作空间
def is_reachable(target_pos):
    distance = np.linalg.norm(target_pos)
    return 0.1 < distance < 0.6  # AIRBOT Play 工作范围

# 方法 2: 增加阻尼
self.end_effector_task = mink.FrameTask(
    lm_damping=10.0,  # 原 1.0
)

# 方法 3: 更好的初值
self.configuration.q = neutral_posture  # 中位姿
```
