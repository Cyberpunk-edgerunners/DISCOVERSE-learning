## 二、状态机设计对比

### 2.1 标准流程（place_coffeecup.py）

```
[IDLE] → [MOVE_TO_GRASP] → [GRASP] → [LIFT] → [MOVE_TO_PLACE] 
  → [PLACE] → [RELEASE] → [RETREAT] → [SUCCESS]
```

**状态数**：9  
**平均耗时**：8-12 秒  
**成功率**：~95%（无域随机化）

### 2.2 复杂流程（open_drawer.py）

```
[IDLE] → [APPROACH_HANDLE] → [GRASP_HANDLE] → [PULL_OPEN] 
  → [VERIFY_OPEN] → [RELEASE] → [RETREAT] → [SUCCESS]
            ↓ (检测到卡滞)
        [ADJUST_ANGLE] → [RETRY_PULL]
```

**关键差异**：
- 新增 `VERIFY_OPEN` 状态：检查抽屉是否真正打开（距离传感器）
- 新增 `ADJUST_ANGLE` 分支：处理拉动角度不当导致的卡滞
- 力控反馈：超过阈值力矩则判定卡滞

**代码片段**：
```python
class PullOpenState(State):
    def step(self, env):
        # 读取末端力传感器
        force = env.get_end_effector_force()
        
        if force > FORCE_THRESHOLD:
            # 卡滞，尝试调整角度
            return "ADJUST_ANGLE"
        
        # 正常拉动
        target_pos = self.start_pos + self.pull_direction * self.pull_distance
        env.move_to(target_pos)
        
        if self.is_done():
            return "VERIFY_OPEN"
```

### 2.3 非抓取流程（push_mouse.py）

```
[IDLE] → [APPROACH_MOUSE] → [ALIGN_PUSH_DIRECTION] → [PUSH] 
  → [VERIFY_POSITION] → [RETREAT] → [SUCCESS]
```

**关键差异**：
- **无 GRASP/RELEASE 状态**：夹爪保持张开
- **ALIGN_PUSH_DIRECTION**：调整机械臂姿态使推动方向精确
- **VERIFY_POSITION**：视觉检测鼠标是否移动到目标位置

**力控策略**：
```python
class PushState(State):
    def step(self, env):
        # 恒力推动模式（阻抗控制）
        target_force = 5.0  # N
        current_force = env.get_contact_force()
        
        # PID 控制力
        velocity = self.pid.compute(target_force - current_force)
        env.set_end_effector_velocity(velocity)
```

## 三、Domain Randomization 对比

### 3.1 基础随机化（place_block.py）

```python
def domain_randomization(self):
    # 1. 物体位置：XY 平面 ±5cm
    block_pos = self.object_pose("block")
    block_pos[:2] += np.random.uniform(-0.05, 0.05, 2)
    
    # 2. 桌面高度：±3-7cm
    self.random_table_height("table", ["block"])
    
    # 3. 光照：3 个光源随机开关/位置
    self.random_light()
```

**变化数量**：~1000 种组合

### 3.2 进阶随机化（place_kiwi_fruit.py）

```python
def domain_randomization(self):
    super().domain_randomization()  # 基础随机化
    
    # 4. 物体姿态随机化
    kiwi_quat = self.object_quat("kiwi")
    random_rot = Rotation.from_euler('xyz', np.random.uniform(-15, 15, 3), degrees=True)
    self.set_object_quat("kiwi", (random_rot * Rotation.from_quat(kiwi_quat)).as_quat())
    
    # 5. 物体尺度随机化（±10%）
    scale = np.random.uniform(0.9, 1.1)
    self.mj_model.geom("kiwi_geom").size *= scale
    
    # 6. 物理属性随机化
    self.mj_model.geom("kiwi_geom").friction = np.random.uniform(0.3, 1.2, 3)
    self.mj_model.body("kiwi").mass *= np.random.uniform(0.8, 1.2)
```

**变化数量**：~100,000 种组合

**变化数量**：>1,000,000 种组合

## 四、IK 控制策略对比

### 4.1 位置控制（place_coffeecup.py）

```python
def compute_target_joints(self, target_pose):
    """纯位置 IK，不考虑速度/加速度"""
    pos, quat = target_pose
    target_qpos = self.ik_solver.properIK(pos, Rotation.from_quat(quat).as_matrix())
    return target_qpos
```

**适用场景**：刚性物体、慢速操作  
**控制频率**：125Hz  
**典型误差**：位置 <2mm，姿态 <3°

### 4.2 轨迹插值（stack_block.py）

```python
def plan_trajectory(self, start_pose, end_pose, duration=2.0):
    """五次多项式插值生成平滑轨迹"""
    t = np.linspace(0, duration, int(duration * 125))  # 125Hz
    
    # 五次多项式系数（确保起止速度/加速度为0）
    tau = t / duration
    s = 6 * tau**5 - 15 * tau**4 + 10 * tau**3
    
    # 插值位置
    pos_traj = start_pose[:3] + (end_pose[:3] - start_pose[:3]) * s[:, None]
    
    # 插值姿态（球面线性插值）
    quat_traj = Rotation.from_quat(start_pose[3:]).slerp(
        Rotation.from_quat(end_pose[3:]), tau
    ).as_quat()
    
    return np.hstack([pos_traj, quat_traj])
```

**优点**：
- 运动平滑，无抖动
- 关节加速度连续，减少磨损
- 避免突然加速导致物体滑落

### 4.3 阻抗控制（open_drawer.py）

```python
def impedance_control(self, target_pose, stiffness=1000, damping=50):
    """
    阻抗控制：模拟弹簧-阻尼系统
    
    τ = K_p * (x_d - x) + K_d * (ẋ_d - ẋ)
    """
    current_pose = self.get_end_effector_pose()
    current_vel = self.get_end_effector_velocity()
    
    # 位置误差 → 力
    pos_error = target_pose[:3] - current_pose[:3]
    force = stiffness * pos_error - damping * current_vel[:3]
    
    # 姿态误差 → 力矩（使用旋转向量）
    ori_error = (Rotation.from_quat(target_pose[3:]) * 
                 Rotation.from_quat(current_pose[3:]).inv()).as_rotvec()
    torque = stiffness * ori_error - damping * current_vel[3:]
    
    # 雅可比转置映射到关节力矩
    J = self.compute_jacobian()
    tau = J.T @ np.concatenate([force, torque])
    
    return tau
```

**适用场景**：需要力反馈的接触任务（开抽屉、插孔）  
**控制频率**：500Hz（比位置控制高 4 倍）

## 五、成功检测逻辑对比

### 5.1 几何检测（place_coffeecup.py）

```python
def check_success(self):
    """检查杯子是否在目标区域内"""
    cup_pos = self.object_pose("coffeecup")[:3]
    target_pos = self.target_zone_center
    
    # 位置误差 < 2cm 且直立
    pos_ok = np.linalg.norm(cup_pos[:2] - target_pos[:2]) < 0.02
    upright_ok = cup_pos[2] > 0.1  # 未倾倒
    
    return pos_ok and upright_ok
```

### 5.2 物理检测（stack_block.py）

```python
def check_success(self):
    """检查上层积木是否稳定堆叠"""
    block_top = self.mj_data.body("block_top")
    block_bottom = self.mj_data.body("block_bottom")
    
    # 1. 位置对齐
    aligned = np.linalg.norm(block_top.xpos[:2] - block_bottom.xpos[:2]) < 0.01
    
    # 2. 接触检测
    contact_force = self.get_contact_force("block_top", "block_bottom")
    in_contact = contact_force > 0.5  # N
    
    # 3. 稳定性检测（速度接近0）
    stable = np.linalg.norm(block_top.cvel) < 0.01
    
    return aligned and in_contact and stable and self.delay_cnt > 50  # 稳定 0.4s
```

### 5.3 视觉检测（close_laptop.py）

```python
def check_success(self):
    """视觉检测笔记本是否合盖"""
    # 1. 关节角度检测
    hinge_angle = self.mj_data.joint("laptop_hinge").qpos[0]
    angle_ok = abs(hinge_angle) < 5 * np.pi / 180  # <5°
    
    # 2. 视觉确认（检测屏幕是否可见）
    img = self.render_camera(camera_id=0)
    screen_visible = self.detect_laptop_screen(img)  # 使用模板匹配
    
    return angle_ok and not screen_visible
```

## 八、最佳实践总结

### 8.1 状态机设计原则

1. **单一职责**：每个状态只做一件事
2. **明确转移条件**：避免模糊的"差不多完成"
3. **失败处理**：每个状态都应有超时和失败分支
4. **可恢复性**：关键状态支持 retry

### 8.2 Domain Randomization 指南

| 随机化维度 | 推荐范围 | 风险 |
|-----------|---------|------|
| 物体位置 | ±5cm | 低 |
| 桌面高度 | ±5cm | 低 |
| 光照 | 全随机 | 低 |
| 物体姿态 | ±15° | 中（可能不可达） |
| 物体尺度 | ±10% | 中（改变抓取点） |
| 物理属性 | ±20% | 高（影响动力学） |
| 相机外参 | ±2mm | 高（破坏标定） |

### 8.3 调试技巧

**问题 1：夹爪抓不住物体**

# 检查接触力

**问题 2：IK 求解失败**

        qpos = self.ik_solver.properIK(*target_pose)

**问题 3：状态机卡住**
```python
# 每个状态添加超时
class StateWithTimeout(State):
    def __init__(self, timeout=5.0):
        self.timeout = timeout
        self.start_time = None
    
    def enter(self, env):
        self.start_time = env.sim_time
    
    def step(self, env):
        if env.sim_time - self.start_time > self.timeout:
            print(f"State {self.name} timeout!")
            return "FAIL"
```
